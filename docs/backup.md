# 백업과 복원

- 사이트 → **백업** 탭에서 `지금 백업`을 누르면 바로 백업합니다. 데이터베이스와 사이트 파일이 함께 저장됩니다.
  - 사이트 파일 백업에는 `node_modules` · `.venv` 폴더를 넣지 않습니다. 복원하면 자동으로 **적용**이 실행되어 패키지를 다시 설치하고 서비스를 다시 시작합니다.
- **백업 예약**은 원하는 만큼 추가할 수 있습니다 (왼쪽 메뉴 **백업** → **+ 예약 추가**).
  - **대상**: 앱 하나 / 데이터베이스 하나 / 전체
  - **주기**: 매시간 / 매일 / 매주 (요일·시각 선택)
  - **보관 개수**: 최근 몇 개를 남길지. 오래된 것은 자동으로 지웁니다.
  - 예약마다 **지금 실행 · 끄기/켜기 · 수정 · 삭제**를 할 수 있습니다. 삭제할 때 그 예약이 만든 백업 파일도 지울지 고릅니다.
- 백업 목록에서 **다운로드**하거나, **복원**을 눌러 그 시점으로 되돌릴 수 있습니다.

## 백업 저장 위치 바꾸기

기본으로 백업은 `/var/lib/rpanel/backups` 에 저장됩니다. 큰 디스크를 따로 붙였다면 **설정 → 저장 위치**에서 바꿀 수 있습니다.

1. 새 디스크를 서버에 연결(마운트)해 둡니다. 예: `/data`
2. **설정 → 저장 위치 → 백업** 칸에 `/data/rpanel-backups` 처럼 **비어 있거나 아직 없는 폴더**를 적고 **옮기기**를 누릅니다.
3. 지금까지의 백업을 새 위치로 복사한 뒤, 예전 위치의 사본은 지웁니다. 진행 기록은 같은 화면 아래에 보입니다.

- 새 위치는 원래 경로(`/var/lib/rpanel/backups`)에 연결(bind mount)되므로 다운로드·복원 등은 그대로 동작하고, 재부팅해도 유지됩니다.
- `/etc`, `/usr`, `/var`, `/home`, `/tmp` 같은 시스템 폴더 안이나, 권한을 저장하지 못하는 FAT·exFAT·NTFS 디스크는 고를 수 없습니다.
- **기본 위치로** 버튼으로 언제든 되돌릴 수 있습니다.
- 같은 화면에서 **프로젝트 파일**(앱 실행 파일 · data 폴더 · 정적 파일 · 빌드 폴더)의 위치도 바꿀 수 있습니다. 이때는 마지막 복사 동안 실행 중인 앱이 잠깐 멈춥니다. 파일 사이트(사이트 계정)의 파일은 `/home` 에 있어 옮기지 않습니다.
- 배포·백업·DB 버전 바꾸기가 진행 중이면 끝난 뒤에 옮길 수 있습니다.

> 백업 파일은 같은 서버에 저장됩니다. 서버 자체가 고장 나는 경우에 대비해서, 중요한 서비스는 백업 파일을 가끔 내 컴퓨터로 내려받아 두세요.
