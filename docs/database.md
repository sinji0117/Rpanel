# 데이터베이스 쓰기 (MariaDB · MongoDB · Redis)

1. 사이트(또는 앱) → **데이터베이스** 탭에서 `+ 데이터베이스`를 누르고 `만들기`를 누릅니다.
2. 접속 주소가 `DATABASE_URL` 환경변수로 프로그램에 자동으로 전달됩니다. 코드에서는 이렇게 읽으면 됩니다.
   ```rust
   let url = std::env::var("DATABASE_URL")?; // mysql://사용자:비밀번호@127.0.0.1:3306/DB이름
   ```
3. Redis가 필요하면 같은 탭에서 Redis를 배정합니다. `REDIS_URL`로 전달됩니다.
4. 다른 설정값(API 키 등)은 **환경변수** 탭에 넣으면 프로그램에 전달됩니다. 바꾼 뒤에는 **적용**(또는 **배포**)을 눌러야 반영됩니다.

## 계정 추가·삭제 (왼쪽 메뉴 **MariaDB** · **Redis**)

**MariaDB** 메뉴:

- **+ 데이터베이스**: 앱과 상관없이 데이터베이스를 만들 수 있습니다. 나중에 **앱 연결**로 원하는 앱에 붙일 수 있습니다.
- **+ 계정**: 데이터베이스마다 계정을 더 만듭니다. 권한은 **읽기·쓰기** 또는 **읽기 전용** 중에 고릅니다. 비밀번호는 직접 정하거나 자동으로 만듭니다.
- **비밀번호 변경 / 삭제**: 계정 줄 오른쪽 버튼으로 합니다. (기본 계정은 지울 수 없고, 데이터베이스를 지우면 함께 지워집니다.)

**Redis** 메뉴:

- **+ Redis 계정**: 프로그램마다 Redis 계정을 따로 만듭니다.
  - **쓸 수 있는 키**: 예를 들어 `shop:*` 로 정하면 `shop:`으로 시작하는 키만 읽고 쓸 수 있습니다. 다른 프로그램의 데이터를 건드릴 수 없습니다.
  - **읽기 전용**을 켜면 읽기만 가능합니다. `FLUSHALL`처럼 전체를 지우는 명령은 어느 계정이든 막혀 있습니다.
- 계정을 만들거나 비밀번호를 바꾸면 **접속 주소**가 한 번 크게 표시됩니다. 목록에서 **보기**를 눌러 다시 볼 수 있습니다.

## DB 웹 관리 (브라우저에서 데이터 보기·고치기)

**패널 관리자**: **MariaDB** 메뉴 → 데이터베이스 줄의 **웹 관리**

- 왼쪽에서 테이블을 고르면 데이터가 나옵니다. **구조** 탭에서 컬럼 형식·키·기본값을 봅니다.
- **+ 행 추가**, 각 줄의 **수정 · 삭제**로 데이터를 고칩니다. (기본 키(PRIMARY KEY)가 없는 테이블은 SQL 로 고칩니다.)
- **▶ SQL 실행**: SQL 을 넣고 `Ctrl+Enter`. 결과는 최대 1000줄, 한 번에 30초까지 실행합니다.
- 패널 root 계정이 아니라 **그 DB 의 기본 계정** 권한으로 실행하므로 다른 DB 는 건드릴 수 없습니다.

**개발자 (패널 계정 없이)**: `https://패널주소/db`

- MariaDB **계정 이름과 비밀번호**로 로그인합니다. 그 계정이 볼 수 있는 데이터베이스만 나옵니다. (예: 읽기 전용 계정으로 로그인하면 보기만 됩니다.)
- 로그인은 2시간 동안 아무것도 안 하면 끝납니다. 비밀번호를 여러 번 틀리면 5분 동안 막힙니다.
- `root` 와 패널 자신의 계정·데이터베이스는 이 화면에서 쓸 수 없습니다.

## DB 버전 바꾸기 (시스템 → 런타임 → **데이터베이스** 탭)

MariaDB · MongoDB · Redis 의 지금 버전을 보고, **더 높은 버전**으로 바꿀 수 있습니다.

| DB | 고를 수 있는 버전 |
|---|---|
| MariaDB | `10.11` (Ubuntu 24.04 기본) · `11.4` · `11.8` (모두 LTS, MariaDB 공식 저장소) |
| MongoDB | `8.0` · `8.2` |
| Redis | `7.0` (Ubuntu 기본) · `8` (packages.redis.io) |

- 바꾸기 전에 **전체 백업**을 `/var/lib/rpanel/backups/_engines` 에 자동으로 만듭니다 (DB 마다 최근 5개).
- 바꾸는 동안 DB 가 잠깐(수십 초) 멈춥니다. 사람이 적은 시간에 하세요.
- 데이터 형식이 바뀌므로 **낮은 버전으로는 되돌릴 수 없습니다.** 확인 창에 `mariadb 11.4` 처럼 입력해야 진행됩니다.
- 런타임(언어)과 달리 DB 서버는 한 서버에 한 버전만 돌 수 있어서, 앱마다 다른 버전을 고를 수는 없습니다.

## MongoDB (왼쪽 메뉴 **MongoDB**)

설치할 때 MongoDB 8 도 함께 설치됩니다 (`127.0.0.1` 에서만 열리고, 로그인이 필요합니다).

- **+ MongoDB 데이터베이스**: 데이터베이스와 그 DB 전용 계정(읽기·쓰기)을 만듭니다. 앱을 고르면 배포(적용) 때 `MONGODB_URL` 환경변수로 들어갑니다.
  ```python
  import os
  from pymongo import MongoClient
  db = MongoClient(os.environ["MONGODB_URL"]).get_default_database()
  ```
- 앱의 **데이터베이스** 탭에서도 **+ MongoDB** 로 바로 만들 수 있습니다.
- 계정 추가(읽기·쓰기 / 읽기 전용), 비밀번호 변경, 지금 백업, 삭제는 **MongoDB** 메뉴에서 합니다. 백업은 MariaDB 처럼 **백업** 메뉴에 나오고 복원할 수 있습니다.
- MongoDB 는 CPU 에 **AVX** 기능이 있어야 합니다. 가상머신(Proxmox 등)이면 CPU 종류를 `host` 로 바꾸세요. AVX 가 없으면 설치를 건너뛰고, 패널은 MariaDB·Redis 만으로 동작합니다.
- 패널 로그(활동 기록·배포 로그·알림·모니터링 기록)도 MongoDB(`rpanel_logs`)에 저장합니다.
