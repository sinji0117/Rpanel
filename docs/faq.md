# 자주 묻는 질문

**집 공유기 뒤에 있거나, 앞에 다른 프록시 서버(Nginx Proxy Manager 등)가 있어요.**
설치 명령 끝에 옵션을 붙여서 "프록시 모드"로 설치하세요. `10.0.0.10` 자리에는 앞단 프록시 서버의 IP를 넣습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/sinji0117/Rpanel/main/install.sh | sudo bash -s -- --mode=proxy --trusted-proxy=10.0.0.10
```

- 이 모드에서는 https 인증서를 **앞단 프록시에서** 발급합니다.
- 앞단 프록시에는 도메인마다 `이 서버 IP:80`으로 연결해 주세요.

**Nginx가 두 군데(앞단 프록시 서버와 이 서버)에 다 있어도 되나요?**
네, **서로 다른 서버라면 괜찮습니다.**
- 앞쪽은 https를 처리해서 넘겨주고, 이 서버는 사이트를 보여 주는 역할을 나눠 맡습니다.
- 문제가 되는 건 **한 서버에 이런 패널을 두 개** 설치할 때입니다. 둘이 같은 자리(80·443 포트)를 차지하려고 싸웁니다.

**프로그램이 시작되지 않아요.**
- **서비스 로그** 탭에서 오류 메시지를 확인하세요.
- 프로그램이 `PORT` 환경변수의 포트로 열고 있는지 확인하세요.
- `exec format error`가 보이면 리눅스용으로 빌드되지 않은 파일입니다([첫 사이트 만들기 4단계](first-site.md#4-실행-파일을-빌드해서-올립니다) 참고).
- `GLIBC_2.xx not found`가 보이면 내 컴퓨터의 리눅스가 서버보다 최신이라 생긴 문제입니다. `cross`로 빌드하거나 Git 자동 배포를 쓰세요.

**PHP 사이트(WordPress 등)도 같이 돌리고 싶어요.**
이 패널은 PHP를 지원하지 않습니다. PHP를 지원하는 다른 호스팅 패널을 **다른 서버**에 설치해서 쓰세요. 필요하면 이 패널의 "연결(리버스 프록시)" 사이트로 그 서버를 연결할 수 있습니다.

**관리자 비밀번호를 잊어버렸어요.**
1. 서버에 SSH로 접속해서 아래를 실행합니다. 패널 관리자 계정만 지워지고, 사이트·데이터는 그대로입니다.
   ```bash
   sudo mariadb rpanel -e "DELETE FROM users"
   ```
2. 다시 `https://서버IP:8443`에 접속하면 관리자 계정을 새로 만드는 화면이 나옵니다.

**사이트 파일 접속 비밀번호를 잊어버렸어요.**
사이트 → **사이트 계정** 탭에서 그 계정의 **비밀번호** 버튼으로 새로 만들 수 있습니다. ([사이트 계정](site-accounts.md))

**패널 주소를 `https://panel.내도메인.com`처럼 쓰고 싶어요.**
1. 도메인 DNS에 `panel` A 레코드를 서버 IP로 추가합니다.
2. 패널 → **설정 → 패널 도메인**에 `panel.내도메인.com`과 이메일을 넣고 **연결**을 누릅니다. 인증서를 자동으로 받고 `https://panel.내도메인.com`(443)으로 열립니다. 기존 `https://서버IP:8443`도 계속 쓸 수 있습니다.
   - 80·443 포트가 인터넷에서 열려 있어야 합니다. (설치 때 `--panel-domain=… --email=…` 옵션으로 넣을 수도 있습니다.)

**패널을 우리 회사(집) IP 에서만 열리게 하고 싶어요.**
**설정 → 패널 접속 IP**에 IP(예: `203.0.113.5`)나 대역(예: `10.0.0.0/24`)을 한 줄에 하나씩 넣고 **적용**을 누릅니다. 지금 접속한 IP 가 빠져 있으면 저장되지 않습니다 (**+ 내 IP 추가**). Git 웹훅(`/api/hooks/`)은 제한하지 않습니다.
- 잠겼다면 서버에 SSH 로 들어가 `sudo /usr/local/lib/rpanel/rpanel-helper panel-access any` 를 실행하면 풀립니다.

**프로젝트로 앱을 만들었는데 사이트 메뉴에서 계정 관리가 안 돼요.**
정상입니다. 프로젝트(Git)로 만든 앱은 코드를 Git 에서 받아 배포하므로 SFTP 사이트 계정이 없습니다. 사이트 목록 **계정** 칸의 `Git 배포`를 누르면 프로젝트 화면으로 가고, 배포·환경변수·DB 는 거기서 관리합니다. 파일을 직접 올려야 하는 사이트는 **사이트** 메뉴에서 만드세요.

**개발자에게 DB만 보여 주고 싶어요.**
MariaDB 메뉴에서 그 DB 에 계정을 하나 더 만들고(필요하면 읽기 전용), `https://패널주소/db` 와 계정 이름·비밀번호를 알려 주세요. 패널 계정 없이 그 DB 만 보고 고칠 수 있습니다. ([데이터베이스 쓰기](database.md#db-웹-관리-브라우저에서-데이터-보기고치기))

**배포하면 `could not read Username for 'https://github.com'` 오류가 나요.**
비공개 저장소를 https 주소로 넣었을 때 나는 오류입니다. Git 주소를 SSH 주소로 바꾸고 Deploy key 를 등록하세요. ([Git으로 자동 배포하기 → 비공개 저장소](git-deploy.md#비공개private-저장소))

**Python 3.13 (또는 다른 Rust·Node.js 버전)을 쓰고 싶어요.**
왼쪽 메뉴 **런타임**에서 설치하고 기본 버전으로 정하거나, 앱마다 **설정** 탭에서 고릅니다. ([언어 버전 (런타임)](runtimes.md))

**지금 쓰는 패널 버전과 최신 버전을 알고 싶어요.**
**대시보드 → 시스템** 카드에 지금 버전과 GitHub 의 최신 버전이 나옵니다. 왼쪽 메뉴 아래에도 새 버전 알림이 뜹니다. 업데이트 방법은 [업데이트와 삭제](update-uninstall.md)를 보세요.
