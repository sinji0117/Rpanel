# 모니터링과 로그

## 대시보드 모니터링

**대시보드 → 모니터링**에 서버 상태 그래프 4개가 있습니다.

| 그래프 | 내용 |
|---|---|
| CPU 사용률 | 전체 CPU 사용률(%) · 오른쪽 위에 지금 값과 CPU 개수 |
| 메모리 사용률 | 사용 중인 메모리(%) · 오른쪽 위에 사용량 / 전체 |
| 디스크 사용률 | 디스크(마운트)마다 한 줄 · 아래에 `/ (371 GB)` 처럼 전체 크기 |
| Load Average | 1분 · 5분 · 15분 평균 부하. CPU 개수보다 계속 높으면 서버가 바쁜 것입니다 |

- 오른쪽 위에서 기간을 고릅니다: **최근 30분 · 1시간 · 6시간 · 24시간 · 7일**.
- 패널이 **1분마다** 기록하고 **7일** 동안 보관합니다 (MongoDB, 없으면 Redis). 처음 설치하면 몇 분 동안은 점이 적습니다.
- 그래프에 마우스를 올리면 그 시각의 값이 나옵니다.

**가동 시간** 카드는 서버가 켜진(부팅) 시각으로 계산해서 계속 갱신합니다. 아래에 부팅 시각과 패널이 켜진 지 얼마나 됐는지가 나옵니다.

## 로그 메뉴

왼쪽 메뉴 **로그**에서 종류별로 봅니다. 검색창으로 원하는 줄만 걸러 볼 수 있습니다.

| 탭 | 내용 |
|---|---|
| 활동 기록 | 관리자가 패널에서 한 일 (로그인, 만들기·바꾸기·지우기), IP |
| 배포 기록 | 모든 앱·사이트의 배포·적용 결과. 누르면 전체 로그 |
| 서비스 로그 | Rust·Python·Node.js·Java 프로그램이 출력한 로그 (앱을 골라서) |
| 사이트 접속 로그 | 사이트별 Nginx 접속·오류 로그와 응답 코드 통계 |
| 크론 로그 | 예약 작업의 실행 결과 |
| 서버 로그 | 패널(Rpanel), 웹 서버(Nginx) 오류, SSH 접속, MariaDB, Redis |

## 화면의 ? 버튼

각 화면과 카드의 설명은 제목 옆 또는 버튼 옆의 **?** 를 누르면 나옵니다. 바깥을 누르거나 `Esc` 로 닫습니다.
