# 알림

왼쪽 위 로고 옆의 **종 아이콘**에 안 읽은 알림 개수가 나옵니다. 누르면 최근 알림이 보이고, 알림을 누르면 관련 화면(배포 로그, 앱, 대시보드 등)으로 갑니다.
전체 목록과 설정은 종 아이콘 → **모두 보기 / 알림 설정** (또는 **설정 → 알림**)에서 봅니다.

**알림** 화면(운영 → 알림)에서는 알림을 **전체 · 배포 · 백업 · 사이트·서버 · 시스템**으로 나눠 보고, **오류 · 경고 · 성공 · 정보** 수준으로 거를 수 있습니다. 목록은 **오늘 · 어제 · 날짜**별로 묶여 나오고, 분류마다 안 읽은 개수가 표시됩니다.

## 알림 받을 일

| 항목 | 언제 | 기본 |
|---|---|---|
| 배포·적용 실패 | 배포나 적용이 실패했을 때 | 켜짐 |
| 배포·적용 성공 | 배포나 적용이 끝났을 때 | 꺼짐 |
| 백업 실패 / 백업 완료 | 지금 백업·예약 백업이 끝났을 때 | 실패만 켜짐 |
| 사이트 응답 없음 · 복구 | 5분마다 확인해서 응답이 없거나(5xx 포함) 다시 살아났을 때 | 켜짐 |
| 디스크 · 메모리 사용량 높음 | 기준(기본 90%)을 넘었을 때. 같은 경고는 몇 시간에 한 번만 | 켜짐 |
| 새 버전 알림 | GitHub 에 새 버전이 나왔을 때 (6시간마다 확인, 버전마다 한 번) | 켜짐 |
| 런타임 설치 결과 | 언어 버전 설치가 끝나거나 실패했을 때 | 켜짐 |
| 관리자 로그인 | 관리자가 로그인했을 때 (IP 포함) | 꺼짐 |

끈 항목은 목록에도 남지 않고 밖으로도 보내지 않습니다. 알림은 최근 1000개까지 보관합니다.

## 보낼 곳 (선택)

비워 두면 패널 안에서만 알립니다. 넣은 곳으로는 켠 알림을 모두 보냅니다. 여러 곳을 함께 써도 됩니다.

| 채널 | 넣을 것 |
|---|---|
| Discord | 채널 설정 → 연동 → 웹후크 → 새 웹후크 → **웹후크 URL 복사** |
| Slack | Slack 앱 "Incoming Webhooks" 로 만든 `https://hooks.slack.com/…` 주소 |
| Telegram | @BotFather 에서 `/newbot` 으로 만든 **봇 토큰** + 봇을 초대한 대화방의 **chat id** |
| 웹훅 | 내 서버 주소. 알림마다 `kind · level · title · body · link · host · at` 를 JSON 으로 POST |

**시험 알림 보내기**를 누르면 저장한 뒤 모든 채널로 시험 메시지를 보내고 결과(성공/실패)를 보여 줍니다.
서버에서 그 주소로 인터넷 연결이 되어야 합니다.
