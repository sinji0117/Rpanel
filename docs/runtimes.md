# 언어 버전 (런타임)

Rpanel 은 언어마다 여러 버전을 설치해 두고, **기본 버전**과 **앱별 버전**을 고를 수 있습니다.
왼쪽 메뉴 **시스템 → 런타임**에서 관리합니다. 화면 위 탭이 **언어**(Rust · Python · Node.js)와 **데이터베이스**(MariaDB · MongoDB · Redis)로 나뉩니다. 데이터베이스 서버 버전은 [데이터베이스 쓰기 → DB 버전 바꾸기](database.md#db-버전-바꾸기)를 보세요.

| 언어 | 어디에 쓰이나 | 처음 기본값 | 고를 수 있는 버전 (예) |
|---|---|---|---|
| **Rust** | Git 자동 배포로 빌드하는 Rust 앱 (`cargo build`) | 최신 안정판 `stable` | `stable` · `beta` · `nightly` · `1.85` · `1.85.0` … |
| **Python** | Python 사이트·앱의 가상환경(`.venv`) | 서버 기본 (Ubuntu 24.04 는 3.12) | `3.10` ~ `3.14` |
| **Node.js** | React·Vue 같은 화면을 Git 에서 빌드할 때 (`npm run build`) | 서버 기본 (설치 시 22) | `20` · `22` · `24` … |

> 내 컴퓨터에서 빌드해서 올리는 **업로드형 Rust 사이트**와 **HTML 사이트**는 서버에서 빌드하지 않으므로 버전을 고를 필요가 없습니다.

## 기본 버전 바꾸기

1. **런타임** 메뉴에서 언어별 **기본 버전** 목록을 엽니다. 목록에 없는 버전은 **직접 입력…**을 고르고 입력합니다.
2. **설치하고 기본으로 변경**을 누릅니다.
   - 아직 없는 버전이면 서버에 **추가로 설치**한 뒤 기본으로 바꿉니다. 설치하는 동안 상태가 `설치 중…`으로 보이고, 끝나면 `사용 가능`이 됩니다.
   - 이미 설치된 버전이면 바로 기본으로 바뀝니다.
3. 설치만 해 두고 기본은 그대로 두려면 **설치만**을 누릅니다.

설치에 실패하면 상태가 `설치 실패`로 바뀝니다. **기록**을 눌러 원인을 보고 **다시 설치**할 수 있습니다. (대부분 서버의 인터넷 연결 문제입니다.)

## 앱마다 다른 버전 쓰기

앱(사이트) → **설정** 탭 맨 위의 **버전**에서 고르고 **저장**합니다.

- **기본 버전 따르기**: 런타임 메뉴의 기본 버전을 씁니다. 기본 버전을 바꾸면 이 앱도 다음 배포부터 따라갑니다.
- 특정 버전을 고르면 기본 버전이 바뀌어도 그 버전을 계속 씁니다.
- 바꾼 버전은 **다음 배포·적용부터** 쓰입니다. Python 사이트는 버전이 바뀌면 가상환경을 새로 만들고 `requirements.txt` 를 다시 설치합니다.

## 지우기

필요 없는 버전은 **삭제**로 지웁니다. 서버 기본 버전, 지금의 기본 버전, 앱이 쓰고 있는 버전은 지울 수 없습니다.

## 어디에 설치되나요?

| 언어 | 위치 | 설치 방법 |
|---|---|---|
| Rust | `/var/lib/rpanel/.rustup` (패널 계정의 rustup) | `rustup toolchain install` |
| Python | `/opt/rpanel/runtimes/python` | [uv](https://github.com/astral-sh/uv) 의 standalone Python |
| Node.js | `/opt/rpanel/runtimes/node/<버전>` | nodejs.org 공식 파일 (SHA-256 확인) |
