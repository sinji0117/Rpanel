# 보안

왼쪽 메뉴 **시스템 → 보안** 에서 서버와 패널의 보안 상태를 한 화면에서 보고 고칩니다.

## 보안 점검

들어가면 바로 아래 항목을 점검해 **위험 · 주의 · 참고 · 안전** 으로 보여 줍니다. 고칠 것이 있으면 **설정하기** 를 눌러 그 화면으로 갑니다.

| 항목 | 안전한 상태 |
|---|---|
| 방화벽 (ufw) | 켜져 있음 |
| SSH root 로그인 | 비밀번호로 root 로그인 불가 (`PermitRootLogin prohibit-password` 또는 `no`) |
| SSH 비밀번호 로그인 | SSH 키로만 로그인 (`PasswordAuthentication no`) — 비밀번호를 쓴다면 fail2ban 권장 |
| 자동 보안 업데이트 | `unattended-upgrades` 켜짐 |
| 패널 접속 IP 제한 | 내 IP 만 허용 |
| 관리자 2단계 인증 | 모든 관리자가 켬 |
| 사이트 HTTPS · 인증서 만료 | 도메인이 있는 사이트는 모두 HTTPS, 인증서가 14일 넘게 남음 |
| 로그인 실패 | 최근 24시간 실패가 적고, 막힌 IP 가 없음 |

## 방화벽

- **켜기 · 끄기**: 켤 때는 SSH 포트와 패널 포트(기본 8443)를 먼저 열어 둡니다.
- **포트 열기**: `3000` 처럼 하나, 또는 `3000:3010` 처럼 범위(이때는 TCP 또는 UDP 를 고름). 출발지 IP 를 넣으면 그 주소에서만 들어올 수 있습니다.
- **IP 차단**: 그 주소(또는 대역)에서 오는 모든 접속을 막습니다. 지금 접속한 내 IP 는 막을 수 없습니다.
- **보호 포트**: SSH · 패널 · 80 · 443 을 여는 규칙은 화면에서 지울 수 없습니다 (스스로 잠기는 것 방지). 꼭 바꿔야 하면 서버에서 `sudo ufw` 로 합니다.

## 로그인 보안

- **패널 접속 IP**: 설정 화면과 같은 기능입니다. 여기에 넣은 IP 에서만 패널을 열 수 있습니다.
- **로그인 시도 제한**: IP · 계정마다 5분에 10번까지 시도할 수 있고, 넘으면 5분 동안 막힙니다. 막힌 IP · 계정을 보고 바로 **해제** 할 수 있습니다.
- **최근 로그인 실패**: 언제, 어느 이메일로, 어느 IP 에서 실패했는지 (비밀번호 틀림 · 인증 코드 틀림).

## 내 로그인 세션

**보안 → 로그인 보안** 맨 위에 지금 내 계정으로 로그인되어 있는 기기(브라우저 · OS), IP, 마지막 사용 시각이 나옵니다.

- 모르는 기기가 있으면 그 줄의 **로그아웃** 을 누르고 비밀번호를 바꾸세요.
- **다른 기기 모두 로그아웃** 은 지금 쓰는 기기만 남기고 모두 끊습니다.

## 2단계 인증 (OTP)

로그인할 때 비밀번호와 함께 휴대폰 인증 앱(Google Authenticator, Microsoft Authenticator, 1Password 등)의 6자리 코드를 넣습니다.

1. **보안 → 2단계 인증 → 켜기**
2. 인증 앱으로 QR 코드를 찍습니다 (안 되면 아래 키를 직접 입력).
3. 앱의 6자리 코드를 넣으면 켜지고, **복구 코드 10개** 가 한 번만 나옵니다. 파일로 저장하거나 복사해 두세요.

- **휴대폰을 잃었을 때**: 로그인 화면의 코드 칸에 복구 코드를 넣습니다. 복구 코드는 하나씩 한 번만 쓸 수 있습니다.
- **복구 코드도 없을 때**: 다른 관리자가 **관리자** 화면에서 그 계정의 **2단계 인증 초기화** 를 누르면 됩니다. 관리자가 한 명뿐이라면 서버에서 직접 풉니다:

  ```bash
  sudo mysql rpanel -e "UPDATE users SET totp_enabled=0, totp_secret=NULL, totp_recovery=NULL WHERE email='me@example.com'"
  ```

- **모든 관리자에게 필수** (관리자만): 2단계 인증 화면 아래 스위치를 켜면, 아직 등록하지 않은 관리자는 로그인하자마자 등록 화면만 보이고 등록을 마쳐야 패널을 쓸 수 있습니다. 내가 먼저 등록해야 켤 수 있고, 켜져 있는 동안은 아무도 2단계 인증을 끌 수 없습니다.
- 인증 앱 비밀키는 서버에 암호화해서 저장합니다. 서버의 `JWT_SECRET` 을 바꾸면 모두 다시 등록해야 합니다.
- 휴대폰 시간이 틀리면 코드가 맞지 않습니다. 휴대폰 설정에서 **시간 자동 설정** 을 켜세요.

## 보기 전용 계정

**관리자** 화면에서 계정을 추가할 때 역할을 **보기 전용** 으로 고르면, 그 계정은 화면을 둘러볼 수만 있습니다.

- 사이트 · 배포 기록 · 로그 · 모니터링 · 보안 점검은 볼 수 있습니다.
- 만들기 · 바꾸기 · 지우기 · 배포는 할 수 없습니다 (내 비밀번호 · 2단계 인증 · 로그인 세션은 직접 관리).
- 환경변수 · Git 웹훅 토큰 · DB 접속 정보 · DB 웹 관리 · 파일 · 백업 내려받기 · 알림 채널 설정처럼 비밀이 보이는 곳은 볼 수 없습니다.
- 역할을 바꾸면 그 계정은 로그아웃되고, 다시 로그인하면 새 역할이 적용됩니다.

## 알림

보안과 관련된 일은 [알림](notifications.md)으로도 받을 수 있습니다: 보안 변경, 로그인 시도 제한에 걸림, SSL 인증서 만료 임박.
